# Odin Recipes

A simple, multi-page recipe website built entirely with pure HTML to practice and consolidate core web development fundamentals.

## About the Project

This project serves as the first hands-on exercise in the fundamental of web from scratch using only html basics. It consists of a main index page linking to several individual recipe pages, demonstrating semantic document layout, relative file paths, and basic media embedding.

## Odin-recipe File project

    Odin-recipes/
    ├── docs/                          # Documentation files
    ├── recipes/                       # A folder for handling recipe page
    │   ├── chicken.html               # Chicken recipe page
    │   ├── honey_garlic.html          # Honey recipe page
    │   └── tomato_basil.html          #  tomato recipe page
    ├── index.html                     #  Main entry of the odin-recipe project
    └── README.md                      # Project overview

## Skills Practiced

* **Document Structure:** Setting up standard HTML5 boilerplate (`<!DOCTYPE html>`, `<html>`, `<head>`, and `<body>`).
* **Text Formatting:** Organizing content hierarchically using headings (`<h1>`–`<h3>`) and paragraphs (`<p>`).
* **Lists:** Structuring recipe ingredients with unordered lists (`<ul>`) and step-by-step instructions with ordered lists (`<ol>`).
* **Links & Navigation:** Connecting the main index page to individual recipe pages using anchor tags (`<a>`) and relative paths.
* **Images:** Embedding food photography using `<img>` tags with descriptive `alt` attributes for accessibility.
* **Git and Github:** Working with git and github. Pushing `git pull filename` and pulling `git push filename` using the terminal.Resolving git conflicts and git branches(detached branch).
* **Markdown:** Writing my markdown file to describe by project's learning process with commands like `*`,`#` `** **` to write my good markdown file.
